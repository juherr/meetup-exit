<objective>
Persist entity errors during `export`: write each independent entity failure to `raw/errors.jsonl` (ArchiveRecord shape) and accumulate the same errors in memory to produce `reports/errors.md` at the end of every export — clean or otherwise.

Purpose: After an export completes, the user has a structured, auditable record of every entity that failed (which event-details could not be fetched, which RSVP pages errored, which registration-answers blocks timed out), without changing the existing "continue on entity error, stop on auth error" policy.
Output: Extended `ArchiveRecord.entityType` union, new `src/archive/errors-report.ts`, three catch blocks in `runExport` writing error records, a new "errors.jsonl" `JsonlWriter`, an always-written `reports/errors.md`, and a unit test for the report writer.
</objective>
