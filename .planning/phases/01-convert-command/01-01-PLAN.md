Create `src/export/convert.ts` implementing `runConvert`. This is the API-free mirror of `runExport` in `src/export/orchestrator.ts`.

**Types to export:**
```typescript
export type ConvertOptions = {
  inputDir: string;   // path to existing export dir (contains raw/*.jsonl)
  outDir: string;     // path to write CSV/Markdown output
  includeMarkdown: boolean;
  privacyMode: PrivacyMode;
  pseudonymizationSalt?: string;
  dryRun: boolean;
};

export type ConvertCounts = {
  groups: number;
  events: number;
  rsvps: number;
  registrationAnswers: number;
  errors: number;
};
```

**Implementation of `runConvert`:**

1. **Discover JSONL files.** Check for existence of at least one of: `raw/groups.jsonl`, `raw/event-details.jsonl`, `raw/rsvps.jsonl`, `raw/registration-answers.jsonl` inside `inputDir`. If none exist, throw an `Error` with message: `"No raw JSONL files found in ${inputDir}/raw — nothing to convert"`. Use `fs/promises` `access` to test existence.

2. **Parse JSONL helper.** Write a module-private async generator `readJsonlRecords(filePath: string)` that yields `ArchiveRecord` objects. Use `Bun.file(filePath).text()` to read the file, split by `\n`, filter empty lines, then `JSON.parse` each line as `ArchiveRecord`. If the file does not exist (catch ENOENT), yield nothing (treat as absent).

3. **Build row arrays.** Iterate each JSONL file and build the same row arrays as the orchestrator:
   - `raw/groups.jsonl` → entityType `"group"` → cast `record.raw` as the group shape (fields: `id`, `name`, `urlname`, `memberCount` — use `unknown` cast to `Record<string, unknown>` and access fields as strings, defaulting to `""` for missing) → push `GroupCsvRow`.
   - `raw/event-details.jsonl` → entityType `"event-details"` → cast raw to access event details fields. Extract the same fields that `orchestrator.ts` uses: `id`, `group.id`, `group.name`, `group.urlname`, `title`, `eventUrl`, `dateTime`, `duration`, `eventHosts[]` (each `{memberId, name}`), `featuredEventPhoto` (`{id, baseUrl}`). Use `unknown` cast with typed extraction helpers. Push `EventCsvRow`.
   - For Markdown: if `includeMarkdown && !dryRun`, apply pseudonymization to hosts (same logic as orchestrator lines 201-212), then call `writeEventMarkdown(markdownEventsDir, eventForMarkdown, privacyMode)`.
   - `raw/rsvps.jsonl` → entityType `"rsvp"` → extract `id`, `memberId`, `memberName`, `memberEmail` from raw, plus `parentIds.eventId`. Skip if `privacyMode === "public-archive"`. Apply `applyRsvpPrivacy` and `applyAttendeePrivacy`. Push to both `rsvpCsvRows` and `attendeeCsvRows`.
   - `raw/registration-answers.jsonl` → entityType `"registration-answer"` → extract `question`, `answer` from raw, plus `parentIds.eventId`. Skip if `privacyMode === "public-archive"`. Need event titles — build a `Map<eventId, title>` from the event-details pass before processing answers. Push `RegistrationAnswerCsvRow`.

4. **Write outputs** (only if `!dryRun`):
   - `mkdir(join(outDir, "csv"), { recursive: true })`
   - If `includeMarkdown`: `mkdir(join(outDir, "markdown", "events"), { recursive: true })`
   - Call `writeGroupsCsv`, `writeEventsCsv`, `writeRsvpsCsv`, `writeAttendeesCsv`, `writeRegistrationAnswersCsv` — same pattern as orchestrator lines 321-335. Only write if the corresponding row array is non-empty.
   - Call `writeChecksums(outDir)`.

5. **Dry-run logging.** If `dryRun`, log what would have been written (match orchestrator lines 376-383 style). Use `logger: Logger` parameter.

6. **Imports.** Import from: `node:fs/promises` (mkdir, access), `node:path` (join), `node:crypto` (randomBytes — for salt generation in pseudonymized mode when no salt provided), `../archive/csv/index.ts`, `../archive/markdown/index.ts`, `../archive/checksums.ts`, `../archive/types.ts`, `../privacy/index.ts`, `../logging/index.ts`.

7. **Salt handling.** Same as orchestrator: if `privacyMode === "pseudonymized"` and no salt provided, generate random salt with `randomBytes(32).toString("hex")` and warn via logger.

8. **No `any` types.** Use `unknown` for the raw JSONL fields. Extract values using safe casts: `(record.raw as Record<string, unknown>).fieldName as string ?? ""`. For nested objects use multiple casts. For nullable values (e.g., `memberEmail`) check for `null`/`undefined` and normalize to `null`.

Re-export `PRIVACY_MODES` and `PrivacyMode` from privacy module for use by the CLI command.

Create `src/cli/commands/convert.ts` — the Commander command for `convert`.

**Structure:** Mirror `src/cli/commands/export.ts` but strip out auth options and network options. No `addAuthOptions`, no `--network`, no `--include-*` flags (convert always processes whatever JSONL files exist), no `--page-size`, no `--event-status`.

**Options:**
```typescript
type ConvertOpts = {
  input: string;         // --input <dir>  (required)
  out: string;           // --out <dir>    (required)
  includeMarkdown?: true; // --include-markdown
  privacyMode: string;   // --privacy-mode, default env or "full"
  pseudonymizationSalt?: string; // --pseudonymization-salt
  dryRun?: true;         // --dry-run
  jsonLogs?: true;       // --json-logs
};
```

**Env var bindings** (same pattern as export command):
- `--privacy-mode`: `process.env["MEETUP_PRIVACY_MODE"] ?? "full"`
- `--pseudonymization-salt`: `process.env["MEETUP_PSEUDONYMIZATION_SALT"]`

**Action handler:**
1. Create logger: `createLogger(opts.jsonLogs === true)`.
2. Validate `privacyMode` against `PRIVACY_MODES`. On failure: `logger.error(...)`, `process.exit(5)`.
3. Call `runConvert({ inputDir: opts.input, outDir: opts.out, includeMarkdown: opts.includeMarkdown === true, privacyMode, pseudonymizationSalt: opts.pseudonymizationSalt, dryRun: opts.dryRun === true }, logger)`.
4. Catch the "No raw JSONL files found" error: `logger.error(error.message)`, `process.exit(1)`.
5. Catch other errors: `logger.error(...)`, `process.exit(1)`.
6. On success: print counts to `console.log` in same format as the export command. If `counts.errors > 0`, `process.exit(4)`.

**Note:** `runConvert` signature is `runConvert(options: ConvertOptions, logger: Logger): Promise<ConvertCounts>` — pass logger as the second argument.

- Add `.addCommand(convertCommand)` after `.addCommand(exportCommand)`.

Do not reorder existing commands.
